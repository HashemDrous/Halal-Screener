# Halal Screener — TradingView Indicator

Shows Shariah-compliance status (Halal / Questionable / Haram) for 
3,100+ US stocks directly on your TradingView chart, plus a screener filter.

## What it does
- 🟢 Halal — passes AAOIFI financial screening
- 🟡 Questionable — borderline ratios
- 🔴 Haram — fails screening
- Compliance grade (A+ to F) per stock

Data source: HalalScreener API (AAOIFI standard).

## How to use
1. Copy `halal_indicator.pine`
2. Open TradingView → Pine Editor
3. Paste → Add to Chart

Research tool, not a fatwa. Different scholars may disagree.
